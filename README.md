# 农民天气播报 weather-farmer

给爸妈用的天气语音播报网页：打开就是一个大按钮，点一下，自动定位 → 取天气 → 用大白话把天气和种地提醒念出来。不用注册、不用安装，手机浏览器直接用。

## 在线使用

GitHub Pages 地址：`https://guoyao-weather.github.io/weather-farmer/`（如未开启，到仓库 Settings → Pages → 选择 main 分支即可）

## 功能

- 📍 自动定位（GPS → IP → 默认襄阳，三级兜底）
- 🔊 语音播报：现在天气 + 未来三天降雨时段（几点下、下多大、下多久）+ 逐日预报
- 🌾 种地提醒：下雨不打药、风大不喷药、高温防暑、低温保暖
- 👆 长按按钮切换语速（慢 / 正常 / 快），播报中点击可停止
- 🌙 白天/夜间/雨天/高温自动换背景色
- 数据源：open-meteo 为主，wttr.in 备用，网络差也能出结果

## 技术说明

纯静态单文件 `index.html`，无构建、无依赖、无后端；语音用浏览器自带 SpeechSynthesis（建议 Chrome / 安卓默认浏览器）。
